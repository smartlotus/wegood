# WeGood · 情侣互动 App

把两颗心连在一起：配对绑定、一键发爱心（全屏动画+通知）、纪念日/倒计时、情侣小游戏、**可互动的桌面小组件**。UI 模仿 iOS「健康」App 风格（高饱和彩色圆角卡片 + 大标题）。

- 技术栈：**Android（Kotlin + Jetpack Compose + Material3）** + **Node.js 同步服务端**（SSE 实时推送 + JSON 存储）
- 设计预览：`docs/design/ui-preview.html`（浏览器直接打开）· 图标源文件 `design/icon.svg`

## 项目结构

```
app/       Android 客户端（Android Studio 直接打开根目录即可）
server/    同步服务端（REST + SSE + 纪念日提醒 tick + JSON 存储）
design/    应用图标 SVG
docs/      设计文档 / UI 预览页
```

## 一、启动服务端（必需）

两台手机要同步，必须先有一个公网可达的服务端（一台最便宜的 VPS 即可）。

```bash
cd server
npm install
PORT=3000 TZ=Asia/Shanghai node index.js     # 生产建议用 pm2
```

- 数据存储在 `server/data/db.json`，备份即拷贝此文件
- `TZ` 影响纪念日提醒的触发时刻，国内服务器用 `Asia/Shanghai`
- 验证：浏览器打开 `http://服务器IP:3000/` 看到 "WeGood 服务端运行中" 即可
- 冒烟测试：`npm test`（自动模拟两台设备完成配对→爱心→纪念日→解绑全流程）

> 本机试玩：`node index.js` 后，模拟器里服务器地址填 `http://10.0.2.2:3000`。

## 二、安装 App

1. `./gradlew :app:assembleDebug` 生成 `app/build/outputs/apk/debug/app-debug.apk`（或直接用 Android Studio 运行）
2. 两部手机都安装，首次打开在「我的 → 服务器地址」或配对页底部填入 `http://你的服务器IP:3000`
3. 按提示授予**通知权限**；建议在「我的 → 实时守护」保持开启（秒级收爱心）；系统设置里允许「精确闹钟」可让纪念日提醒更准时

## 三、配对

1. 手机 A 打开 App，显示 6 位配对码（如 `X7K2QP`）
2. 手机 B 输入该配对码 → 点「绑定 TA」
3. 双方立即收到"已绑定"提示；「我的 → 解除绑定」可随时解绑（会清空共同的纪念日与游戏数据，双方都会收到提示）

## 四、功能清单

| 模块 | 能力 |
|---|---|
| 首页 | "在一起第 N 天"英雄卡、一键发爱心/亲亲/抱抱/玫瑰/想念、最近互动流 |
| 爱心互动 | 对方实时收到：前台→全屏爱心粒子动画+震动；后台→系统通知（前台服务/15 分钟兜底轮询） |
| 纪念日 | 自定义名称+日期（过去=累计天数，未来=倒计时，支持每年重复）、双方实时同步 |
| 提醒 | 每个纪念日可设提前 0/1/3/7 天 + 提醒时刻，到点双方都收通知（本地闹钟+服务端双保险，自动去重） |
| 游戏 | 双人实时井字棋（胜负判定）、每日一问（互相可见答案）、真心话大冒险（内置题库） |
| 小组件 | ① 情侣卡 4×2：在一起天数+对方在线+**免打开 App 直接发互动**+最近动态 ② 一键爱心 2×2 ③ 纪念日倒计时 4×2；收到爱心/上下线/纪念日变更都会实时刷新小组件 |
| 我的 | 昵称、配对码、对方在线状态、通知/闹钟权限引导、实时守护开关、服务器地址、解绑 |

## 五、打包正式版

```bash
./gradlew :app:assembleRelease   # 需要自行配置签名（Android Studio: Build > Generate Signed Bundle/APK）
```

## 六、常见问题

- **收不到通知**：检查系统通知权限 → 「我的」页开关"实时守护" → 允许精确闹钟
- **连接失败**：确认服务端已启动且安全组放行端口；App 内修改服务器地址后自动重连
- **提醒不准时**：服务端用 `TZ=Asia/Shanghai` 启动；手机端授予精确闹钟权限；也可在「我的 → 重排提醒」手动校准
- **小组件不更新**：收到爱心/打开 App 都会刷新；也可长按小组件移除后重新添加
